# Sources and methodology

## Method
This is a practical, non-ranked starting list assembled from public investor ecosystem directories and the organizations' own public homepages. Each organization's official homepage is recorded as both website and source URL. The dataset intentionally avoids claims about current ticket size, stage, sector focus, portfolio, or whether unsolicited submissions are accepted; check those details directly with each organization.

Public ecosystem references used to identify candidates include:

- [Indian Venture and Alternate Capital Association (IVCA)](https://www.ivca.in/)
- [Inc42 India Startup Investor Landscape reports](https://inc42.com/reports/)
- [Startup Telangana investor directory](https://startup.telangana.gov.in/investors/)
- [iHub India](https://ihubindia.com/)
- The official organization pages linked from [investors.json](investors.json)

Candidate inclusion is based on public association with venture investing, startup investment platforms, or angel networks in India. Inclusion is not an endorsement, proof of current investment activity, or financial advice. Links and participation can change; corrections are welcome.

## Badges and YOLO
GitHub's YOLO achievement is associated with merging a pull request without a formal code review. It is GitHub-controlled and not guaranteed; adding artificial issue or pull request steps cannot guarantee a badge. This repository's issue, pull request, and contribution templates are for genuine maintenance. Please do not create empty or repetitive contributions to chase achievements.

Other achievements in the supplied screenshot depend on distinct GitHub actions (such as stars, accepted answers, or pull request activity) and are not produced automatically by repository files. Check GitHub's current [Achievements documentation](https://docs.github.com/en/account-and-profile/reference/profile/achievements) for qualification rules.
