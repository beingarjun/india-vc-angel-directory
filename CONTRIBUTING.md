# Contributing

Thanks for helping keep this directory useful.

## Correcting an entry
1. Check that the proposed URL is controlled by the investor organization and uses HTTPS where available.
2. Open an issue or pull request with the organization name, current official source, and proposed change.
3. Keep the CSV and JSON records in sync. Each record has `name`, `type`, `website`, and `source_url`.
4. Do not add personal email addresses, private contact details, speculative investment preferences, or unsupported claims.

## Adding organizations
Add only a distinct organization with a public association to venture investing or angel investing in India. Explain its relevance with a public source. Keep the dataset at 100 entries unless updating the README count and documenting the scope change.

## Pull requests
Keep changes focused and explain the source and effect. Submit genuine corrections or improvements; do not open empty pull requests to pursue GitHub achievements.
